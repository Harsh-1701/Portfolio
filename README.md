# Portfolio

My personal portfolio website built with Next.js.

Instead of using a template, I wanted something that reflects the way I think about engineering projects and product development.

The portfolio showcases:

- EduNite (Full-stack mentorship platform)
- Skin Cancer Detection using Deep Learning
- AR Educational Tool
- Other software and electronics projects
- Internships and leadership experience

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Vercel

## Running locally

```bash
npm install
npm run dev
